# 今日の日本語 - 일본어 공부 사이트 프로토타입

## 실행 방법
1. `index.html`을 더블클릭합니다.
2. Chrome/Edge/Safari 등 브라우저에서 바로 실행됩니다.
3. 별도 설치나 서버가 필요하지 않습니다.

## 포함 기능
- 오늘의 단어 8개: 명사 2 / 동사 2 / 형용사 2 / 부사 2
- 예문 및 해석
- '외웠어요' 체크
- '이건 알아요'로 단어 교체
- 단어 객관식 테스트
- 오답노트 자동 저장
- 한국어 → 일본어 문장 시험
- 오늘 단어를 활용한 자유 작문 간단 점검
- 브라우저 localStorage에 학습 기록 저장
